# 分级介入（Graded Intervention）设计 —— 紧急态不再整个丢弃策略动作（2026-07-25 later·设计节·未动代码·未烧卡）

> **起因**：四方头条首跑暴露 **追越场景 82.4% 步在紧急态 → 到达 2% → 且带崩全局(对遇/交叉 82%→17-20%) → 连续臂反而输给离散臂(~43%)**。
> **根因（读码坐实）**：`usv_projection.py:423-429` ρ5 → `EmergencyController.step(s_ego, s_obs)` —— **只看状态·根本不传 `u_desired`·策略动作被整个丢弃**。
> **而 ρ0-4 的 P=∅ 兜底(:431+) 却是【分级】的**：`relaxed`(去COLREGs·保无碰撞·**投影 u_desired**) → `collision_min`(软QP·**仍用 u_desired**)。
> ⟹ **分级机制早已存在·ρ5 却跳过它直接掉到最底层 = 不对称·很可能无意。**

## 0 · 为什么这会毁训练（机制链）

```
追越(逼近速度天生慢·在紧急区滞留 480s+) → ρ5 触发 82% 步
  → 策略动作被丢弃 82% → ①无学习信号(梯度全平=混叠极端形态) ②紧急控制器只避碰不去目标(到达2%)
  → 该 1/3 经验产生巨额负回报 → VecNormalize 尺度被其主导 → 对遇/交叉的奖励差异被压平 → 全局带崩
```
**离散臂同样吃 ~30% 紧急却仍能学(~43%)**：动作掩码下策略**仍在被允许动作里做选择**=信号还在;连续臂是**整个被替换**=信号没了。

## 1 · 设计：ρ5 复用【已存在】的分级阶梯

**改动点唯一**：`safe_action` 里 ρ5 分支不再直接调 EC，而是先走与 ρ0-4 相同的阶梯：

| 档 | 条件 | 动作 | 用 u_desired? | source |
|---|---|---|---|---|
| 1 | box∩无碰撞 可行 | 投影 u_desired | ✅ | `emergency_relaxed`(新标) |
| 2 | 上档不可行 | 软QP 最小化最坏侵入 | ✅ | `emergency_collision_min`(新标) |
| 3 | 退化(圆心重合/已碰·无分离方向) | **EmergencyController(Alg.1)** | ❌ | `emergency`(原语义) |

**关键**：Alg.1 **保留为最后一档**（真迫近/已碰时它是设计好的多模式响应）;前两档只是**别把策略的意图扔掉**。

**新 source 标签**必须与原 `emergency` 区分 → 评估/紧急步%/违规归因口径不被静默改动（现有 `_FALLBACK_SOURCES`/紧急步统计须同步更新·否则钱图口径漂移）。

## 2 · 为什么这在方法上站得住

1. **安全不降反升**：现状 ρ5 走 Alg.1 = **纯经验启发式·无碰撞约束根本没施加**（论文已诚实标"非保证"）。新档 1/2 **真正施加了无碰撞约束**（虽是一阶线性化+圆盘近似）→ 对"软 ρ5"（如追越 900m 外）**更合适**。
2. **不破坏忠实复现**：连续盾是**我们自己的贡献**；离散臂仍原样复现 Krasowski → 四方公平性不受影响。
3. **不动可证明层**：ρ5 本来就在可证明层作用域**之外**（诚实 limitation D13）。分级只改"兜底怎么兜"，**不改任何 provable claim**。
4. **对症三件事**：追越失败 / 动作混叠 / 盾诱发崩塌（三者同源=策略在盾接管步收不到信号）。

## 3 · 🔴 风险与必须验的（对抗审重点）

- **R1 真迫近时够不够**：档 1/2 是**单步一阶线性化 + 圆盘近似**；Alg.1 是为迫近设计的多模式（含全速倒车等）。**真迫近时用投影可能比 Alg.1 弱** → **必须 A/B 盯碰撞率**；若碰撞升 → 加"迫近度判据"（如 gap#1 证书/净距阈值）决定用哪档 = **真正的"自适应介入"**。
- **R2 ρ5 语义混杂**：`is_emergency` = "保向 180s 内**可能**撞"，把"追越 900m 外"和"3 秒后撞"混为一档。分级实际是**按可行性隐式分了级**（可行→投影/不可行→Alg.1），但**显式迫近度判据更可控**（留作 v2）。
- **R3 口径漂移**：紧急步% / 违规归因 / `_FALLBACK_SOURCES` / 钱图列 全部依赖 source 标签 → 新标签须同步接线 + 回归测试（否则历史数字不可比）。
- **R4 EC 状态机**：现 EC 有"进入边沿 reset + 驻留续跑"语义（D13 头号静默错误类）。若 ρ5 期间在档1/2 与档3 之间来回切，**EC 的 mode 驻留会错乱** → 须定义清楚：档3 首次进入才 reset？还是每次 ρ5 进入边沿都 reset？**必须显式设计+测试**。
- **R5 bit-identical**：须做成**开关**（默认关=现行为逐位不变），否则所有历史结果不可比。

## 4 · 实施计划（走基础设施最高标准·不冒进）

1. **[本机] 设计（本文）→ ≥2 对抗 agent 审**（重点 R1-R5）。
2. **[本机] 实现**：`graded_emergency: bool = False` 开关（默认关=bit-identical）+ 新 source 标签 + 口径接线 + committed 测试（含 EC reset 语义、开关关时逐位等价）。
3. **[服务器·小] 冒烟**：1 种子短跑，确认不崩 + source 分布出现新标签。
4. **[服务器·小] A/B 小验**：2-3 种子 × {off, on} × 含追越数据集。
   **判据**：① 追越到达率 2% → 显著上升（主靶）② **碰撞率不升**（安全锚点·硬红线）③ 对遇/交叉不回退 ④ 紧急步% 下降或持平。
5. **命中** → 进头条配方，重跑四方（含追越）；**不中** → 追越移出头条，作用域诚实写（见 §5）。

## 5 · 无论成败都要写进论文的发现（作用域贡献）

> **基于可达集的紧急判据与追越在结构上张力**：追越的**低逼近速度**使 `is_emergency`(t_pred=180s·Krasowski Table II) 在整回合 **~82%** 时间保持激活，可证明合规层几乎从不介入、全靠经验兜底。这解释了为何该基准**不含追越场景**，并划定了方法的适用边界。
