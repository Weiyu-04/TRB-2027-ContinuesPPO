# 训练产物回传工具

放在 `结果/` 下是有原因的：`代码/` 与 `Paper/正式实验/` 都进冻结指纹
（`代码/tests/preflight_formal.sh` 会逐字对），训练期往里加文件会让预检当场变红。
`结果/` 不进任何指纹（同 `结果0801-出图草图/`）。

## 用法（Mac 上，两行）

    cd ~/TRB-2027-ContinuesPPO && git pull origin main
    python3 TRB/结果/结果0801-回传工具/trb_upload.py --go

**`--go` 是必须的**——不加它只做只读盘点、什么都不上传（2026-08-01 user 就是漏了它，
以为传上去了、其实一个文件都没动）。

`--go` 模式下**无论有没有产物要传，都会把盘点报告
`_盘点报告.txt` 提交推送**，所以 Claude 那边一定看得到这台机器的真实状态，
不用你复制粘贴终端输出。

想先看不传：去掉 `--go`，报告仍会写到本地，只是不提交。

在服务器上（没有仓库）：直接跑它，会自动切成只盘点模式，把表贴回来即可。

    python3 trb_upload.py /root/trb/结果

## 它防住的坑

| 坑 | 怎么防 |
|---|---|
| 模型权重几百 MB 进 git | 只搬 json/jsonl/txt/log/csv，zip/pkl/pth 一律跳过 |
| 半截存档盖掉完整存档（`03` L243-续19 C） | 同名 `progress.json` 只有段数更多才覆盖 |
| `.gitignore` 静默吞文件（`03` L243-续43 B） | 提交前用 `git status --ignored` 单独列出被挡下的 |
| 命令里夹中文注释被 zsh 当参数（`03` L243-续43 C） | 全部逻辑在脚本里，用户只敲三行无注释命令 |
| 扫到仓库自己、自我复制 | 扫描时跳过仓库路径 |

# 重评 / 轨迹产物：用 `trb_upload_reeval.py`（2026-08-01 later-3 新增）

上面那个 `trb_upload.py` 只认**训练期**产物（文件名带 `F240`），
重评那两趟、轨迹专趟的产物它一个都搬不了 ⟹ 另开一个。

## 用法（Mac 上，两行）

    cd ~/TRB-2027-ContinuesPPO && git pull origin main
    python3 TRB/结果/结果0801-回传工具/trb_upload_reeval.py --go

不加 `--go` 就是只读盘点，一个字节都不动。目录不在 `~/Downloads` 就直接当参数传：

    python3 TRB/结果/结果0801-回传工具/trb_upload_reeval.py ~/Downloads/结果-正式重评+轨迹 --go

## 它把东西放到哪

    TRB/Paper/正式实验/02_重评产物/正式-末段/
                                 正式-最佳/
                                 正式-轨迹全集/
                                 _其他/            （_best.json、各种 _reeval_*.log）
                                 _盘点报告_重评.txt （自动提交，Claude 那边直接看得到）

分类只看**相对源目录的那段路径**：含 `轨迹`/`traj` 归轨迹（先判，否则轨迹目录里的
`g0.json` 会被当成重评那两趟）、含 `末段`/`formal_last` 归末段、含 `最佳`/`formal_best` 归最佳。
`_best.json` 是「挑存档的结果」不是「最佳那趟重评」，单独归 `_其他`。

## 复制之前它会先自查

| 查什么 | 期望 |
|---|---|
| `g*.json` 里 `strict键` 的长度 | **600**（正式实验的分母；小集那代是 563，混了就不可同表）|
| 各组 `strict键` 是否**逐位相同** | 相同。不同 = 分母不同 ⟹ 不可放同一张表 |
| `all.json` 合并到几条臂 | 末段 / 最佳 = **72**（9 臂 × 8 种子）；轨迹专趟 = **27**（9 臂 × 3 种子）|
| 轨迹专趟有没有 `g*_traj.json` | 有。没有的话图 6 画不出来 |

## 它防住的坑（在上面那张表之外）

| 坑 | 怎么防 |
|---|---|
| 单文件 > 90 MB | 默认跳过并单独列出（GitHub 硬上限 100 MB，超了**整次 push 被拒**）。确要传加 `--force-big` |
| 权重 / 压缩包进 git | `zip/pkl/pth/pt/npz/npy/ckpt/tgz/tar/gz` 一律跳过，只搬 `json/jsonl/txt/log/csv/md` |
| 🔴 `git add` 路径带中文时匹配不到 | 路径参数用 `shlex.quote`。**原来两个脚本都用 `json.dumps`，它默认把中文转义成 `\uXXXX`，`git add` 一个文件都匹配不到还不报错**（`03` L243-续47 F，已修）|
