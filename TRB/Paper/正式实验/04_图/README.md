# 图（`Paper/正式实验/04_图/`）

一条命令出全部三张图（PDF 给论文 / PNG 给汇报）：

```bash
python3 -B Paper/正式实验/04_图/make_图.py <重评目录> Paper/正式实验/04_图
```

| 图 | 内容 | 要注意的口径 |
|---|---|---|
| 图1 学习曲线 | 旧配方（金标）10 种子 vs 新配方 C 10 种子 | 🔴 用的是**训练期 40 场景里程碑数**，标题里已标死「不进任何报数表」（`03` L232 铁律）。这张图同时是 `03` L236-A「5.08M 是预算点不是收敛点」的直接证据——旧配方那条中位线到 5M 还在陡升 |
| 图2 三臂消融 | 转艏增量 / 让路违规 / 到达率 | 🔴 **同种子配对**画（只用四条臂共有的种子），不是拿不同种子集比均值（`03` L234-C 那族错）。图上能直接看出「只改状态机治不了转艏、还略变差」 |
| 图3 轨迹对比 | 同一场景下几条臂叠在一起 + 他船虚线 | 轨迹来自**同一趟评估**的 `g*_traj.json`，跨趟不可拼 |

**字体**：脚本自动探测中文字体，没有就整张图退英文标签（不会出豆腐块、也不会挂）。
