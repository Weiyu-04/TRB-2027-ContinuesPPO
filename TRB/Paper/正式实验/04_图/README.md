```bash
python3 -B Paper/正式实验/04_图/make_figures.py <重评目录> Paper/正式实验/04_图
```

## 遵循的绘图规范

按 **nature-figure**（user 2026-07-29 指定）的 Python 后端约定出图。落地为：

| 规范条 | 本项目怎么落的 |
|---|---|
| 五点契约（先写结论/证据链/形制/后端/导出，再写代码）| 写在 `make_figures.py` 顶部的注释块里，每张图一段 |
| 强制可编辑文字 | `svg.fonttype='none'` + `pdf.fonttype=42`，**每个绘图脚本顶部都有一份**（不只放共享层）|
| 后端排他 | 全流程只用 Python/matplotlib，不跨语言出预览 |
| 最终尺寸先定死 | `figsize` 写死英寸（7.20 in = 183 mm 双栏 / 4.72 in = 120 mm），不在出图时才算 |
| 字号 | 5.2–8 pt（密排期刊图区间），面板号小写加粗 |
| 配色 | 规范给的 PALETTE；一张图只用「一个中性族 + 一个信号族 + 一个强调族」；**无彩虹色图**；每条臂的颜色**全项目统一** |
| 图例策略 | 尽量**直接标注**代替图例（Fig.1a/3/4 都是直接标注）|
| 统计进图不进"标题清洁工作" | n=种子数、中心=均值、误差棒=**按种子重采样的 95% 自助法区间**（B=20000·固定随机种子）、检验名与 p 值都写在图上 |
| 导出 | `.svg`（主·可编辑）+ `.pdf`（矢量投稿）+ `.tiff`（600 dpi 投稿栅格）+ `.png`（预览）|
| 交付前静态预检 | 规范自带的 `validate_figure.py`：`make_figures.py` **14 项全过（READY FOR VISUAL QA）** |
| 视觉 QA（预检管不到的）| 人工看渲染图。**已抓出并修掉 Fig.3 的标签重叠/出血**（改短名 + 逐点偏移 + 留白）|

🔴 **图内文字一律英文** —— 论文投 TRB 本来就要英文，且规范要求 Arial/Helvetica 字体族；中文只留在代码注释与本 README。
（`nature_style.py` 是**样式/调色板辅助层、不是绘图脚本**，所以预检里那几条"导出"检查对它不适用。）

## 四张图

| 图 | 核心结论（一句话）| 形制 |
|---|---|---|
| **Fig.1 样本效率**（hero）| 同一 5.08M 步预算下，新配方学习速度快约一个数量级；**旧配方到期时仍未收敛** ⟹ 这是样本效率声明、不是"收敛后更好" | a 学习曲线（hero）+ b 同种子配对哑铃 + c 到期仍在上升的种子占比 |
| **Fig.2 消融** | 两把钥匙各治各的：有界动作分布治转艏抖动、状态机修法治让路违规，缺一不可 | 三格柱状·**只用四条臂共有的种子**·带自助法误差棒 |
| **Fig.3 安全-效率权衡**（钱图）| 带盾连续方案在 Pareto 前沿；无盾基线到达率高但碰撞与违规都高 | 散点·点面积 ∝ 碰撞率·直接标注 |
| **Fig.4 轨迹** | 投影盾产出平顺右转让路，离散基线是满舵摆动 | 四场景小多图·同一趟评估 |

⚠️ Fig.1a 用的是**训练期里程碑数**（40 场景），图注里已标死"train-time milestone" —— 它**永远不进报数表**（`03` L232 铁律）。
