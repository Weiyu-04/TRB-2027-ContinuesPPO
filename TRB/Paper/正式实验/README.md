## §3 已知必须写进论文的诚实口径（**这几条不是可选项**）

1. **"5.08M 是预算点、不是收敛点"**（`03` L236-A）
   实测：金标（旧配方）**8/8 健康种子**在 5M 时仍在明显上升；C 是 **3/10**；Base/Rule-reward 第 3-4 段就打满。
   ✅ 可写"**在同样 5.08M 步预算下** 92.11 vs 58.61"（= **样本效率**声明，是我们真正的卖点）
   🚫 不可写"新配方比旧配方好"（旧配方压根没练完）
   ⟹ **所有表标注"5.08M 步预算 · 末段存档"**。转艏Δ 那条不受影响（有界 vs 无界是结构性的）。

2. **"到达 +43.5 点"必须配第二句**（`03` L234-E④）
   对标 5 颗里崩 2 颗、C 10 颗全活；**只比双方练成的种子，差距缩到 +12.2 点**。
   ⟹ 定式写法：**"C 十颗种子全部练成、对标五颗里崩两颗；即使只比双方练成的种子，C 仍高 12 个点。"**
   （违规 1.77× / 转艏 5.06× / 让路 2.17× 只比健康种子照样赢，不受影响。）
   ⟹ **凡逐局平均的指标，一律同时报"全部种子 / 仅健康种子"两版**（崩种子的污染方向因臂而异）。

3. **"盾把碰撞压 N 倍"要用单变量版**（`03` L234-E⑤）
   干净版 = 同为离散、只差有没有盾：**1.883% → 0.071% = 26.5×**。
   13.25× 那版同时换了"加盾"和"离散→连续"两件事 ⟹ 只能说"我们这一套比无盾基线安全 13 倍"。

4. **碰撞率如实报 0.142%**，写"与对标统计上无差异（Fisher p=0.51）、二者均远低于无盾 1.88%"，**绝不写"零碰撞"**（`03` L232-C·L234-F 复现）。

5. **可证明层措辞守 `CLAUDE.md` §0 的诚实档**：能严证 = 远场单步无碰 + 每让路步方向合规 + 紧急迫近不可避 sound 证书；
   **🚫 绝不写 provably collision-free / provably compliant（裸）**。命题 4（前向不变）仍 PROVISIONAL。

6. **COLREGs 覆盖边界**：R17(a)(ii)/(b)/(c)、R18、R19、R9、R10 未实现（对标论文同样没做·范围一致）；
   **官方场景库无追越**（`benchmark-lacks-overtaking`）⟹ 追越那一路只有合成验证。
