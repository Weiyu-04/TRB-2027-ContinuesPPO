### Q3. 追越场景为零：基准库没有，还是谓词判不出来

**`[实测]` —— 结论：基准库确实不含追越几何，不是合取条件过严。**

命令（在 `TRB/` 下）：对全部 2000 个官方场景，用 `usv_colregs` 的真实谓词逐条拆 ρ4 的四个合取项
（初始时刻几何；脚本见本目录 `Q3_overtake_decompose.py`）。

| 合取项 | 命中场景数 |
|---|---|
| 有效场景 | 2000 |
| `collision_possible` | 210 |
| ① `Be(s_m, s_e)` 本船位于他船后扇区 | **0** |
| ② ① ∧ `Sd` 航向近同向（$\Delta_{\rm ot}=67.5^\circ$） | 0 |
| ③ ② ∧ $v_e>v_m$ | 0 |
| ④ ③ ∧ `collision_possible` = ρ4 | 0 |

**卡在第一个合取项**：本船从未位于他船的后扇区。也就是说，零命中并非由后续三项
（航向带、速度比较、碰撞可能性）叠加造成，而是**该基准的初始会遇几何中不存在"本船从后方接近他船"这一构型**。

⚠️ **边界**：本测量取**初始时刻**几何。理论上回合推进中几何可能演化出追越构型，
本轮未逐步扫描全轨迹，故严格结论为"**初始几何中不存在**"。
