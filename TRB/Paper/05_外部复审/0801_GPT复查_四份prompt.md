# 给 GPT 的四份复查 prompt（2026-08-01）

**用法**：每份**单开一个会话**，把这一份的全文连同论文一起发过去（论文用 `801-paper-英文版_预览.pdf`，
或把 `801-paper-英文版.tex` 与 `_refs.tex` 一起发）。四份**不要合并成一次问**，合并会让它每项都只说两句。

**四份共同的前提**（已写进每一份，不用另外交代）：
- 方法论**冻结**，不接受"换个算法/加个模块/再补个实验"这类建议。
- 输出**中文**，给**可执行的问题清单**，不要写鼓励的话、不要重写整段。
- 每条问题必须给：**位置（节号 + 原句片段）→ 问题是什么 → 改成什么**。
- 拿不准的标 `存疑`，不要为了凑数硬判。

## 【第 1 份】文献与学术道德核查

```
你是一位负责任的学术编辑，现在为一篇投给 TRB（美国交通研究委员会）年会的论文做**引用与学术道德核查**。

前提：
- 论文的方法论已冻结，不要提出任何修改算法、增加实验、调整模型的建议。本次只查引用。
- 用中文回答。输出一份问题清单，不要写评语和鼓励。
- 每条必须写清：位置（节号 + 原句片段）→ 问题 → 建议怎么改。
- 你无法联网核实的，标注「存疑，需人工核实」，不要猜，也不要因为"看起来像真的"就判为通过。

请逐条检查参考文献表里的每一条，以及正文里每一处引用，回答下面六个问题：

1. **是否存在不存在的文献**。逐条核对作者、年份、标题、期刊/会议名、卷期页码是否自洽。
   典型伪造特征：作者与该领域不符、期刊名与主题不搭、卷期与年份对不上、
   会议论文却给了期刊卷号、DOI/arXiv 号格式异常。把每一条判为
   「可确认存在 / 信息自洽但需核实 / 高度可疑」三档之一。

2. **是否存在张冠李戴**。正文某处说「X 提出了 A」，而 A 实际上不是 X 的贡献；
   或把综述当成原始工作引；或把后续工作的结论算到先驱工作头上。
   请逐处核对「这句话主张的内容」与「被引文献实际做的事」是否匹配。

3. **是否存在引用不支持结论的情况**。即引文是真的、作者也对，但它并不能支撑正文那句话。
   特别注意带数字、带阈值、带"首次/唯一"的句子。

4. **是否存在该引而未引**。正文里出现了明显来自他人的参数、阈值、判据、数据集、
   评价口径、公式形式，却没有给出处。这一条比多引更严重，请重点找。

5. **自引与致谢是否得当**。论文致谢里感谢了公开场景库与规则形式化的提供方，
   请判断这个致谢与正文里对该工作的引用是否一致、有没有过度或不足。

6. **引用格式是否统一**。本文用作者-年份制（Chicago author-date），正文 (Author, Year)，
   文献表按第一作者姓氏字母序、悬挂缩进、不编号。请找出格式不一致的条目。

最后给一个总表：文献总数 / 判为「高度可疑」的条数 / 判为「需人工核实」的条数 /
张冠李戴的处数 / 该引未引的处数。
```

## 【第 2 份】叙事与逻辑核查

```
你是一位 TRB 年会的资深审稿人，现在为一篇投稿做**叙事与逻辑严密性**核查。

前提：
- 论文的方法论已冻结，不要提出任何修改算法、增加实验、调整模型的建议。
- 用中文回答。输出一份问题清单，不要写评语和鼓励。
- 每条必须写清：位置（节号 + 原句片段）→ 问题 → 建议怎么改。

本文自己声明的叙事主线是：
「让路条款有方向性 → 合规无法用有没有撞上来验证 → 既有两条路各放弃一项属性 →
本文的洞见：让路条款在控制量平面上恰好是一个半平面 → 于是"枚举并屏蔽"可换成"向凸集投影" →
半平面 ∩ 动作箱 ∩ 单步无碰 = 凸集 → 二维二次规划投影 → 盾在训练回路之内 →
分级说明证了什么、没证什么 → 单变量递进序列把每个机制单独读出来 → 如实报代价。」

请检查：

1. **每一节、每一段是否都落在这条线上**。找出偏离主线、可以整段删掉而不损伤论证的部分。

2. **摘要 / 引言里许下的每一个承诺，正文是否都兑现了**。逐条列出摘要里的主张，
   标注它在正文哪一节被兑现；没兑现的单独列出。

3. **数字是否全篇一致**。同一个量在摘要、正文、表、图注里出现多次时，是否完全一致。
   请把所有出现两次以上的数字列成对照表，标出不一致的。

4. **每一张图、每一张表是否都有配套的分析文字**，且图上画的与正文说的是同一件事、
   同一个数据口径。反过来，正文里描述的现象是否都能在图上看到。
   特别注意：本文的图有的取自训练过程、有的取自测试集，口径不同，
   请检查图注与正文有没有把两者混为一谈。

5. **因果链条是否有跳步**。找出「A 所以 B」但中间缺一环的地方。

6. **结论是否超出证据**。本文明确声明只能严格证明三件事
   （远场单步无碰 / 每个投影可行的让路步方向合规 / 迫近不可避的单向充分条件），
   其余为经验结果。请找出任何在措辞上超出这个范围的句子。

7. **局限是否写全**。找出正文数据里能看出、但局限段没提的问题。

最后给一个总评：叙事完整度打分（1-10）+ 最该先改的三处。
```

## 【第 3 份】语言与体例核查

```
你是一位科技英语编辑，现在为一篇投给 TRB 年会的论文做**语言与体例**核查。

前提：
- 论文的方法论已冻结，不要提出任何修改算法、增加实验、调整模型的建议。
- 用中文回答，但引用原句时保留英文原文。输出问题清单，不要写评语和鼓励。
- 每条必须写清：位置（节号 + 原句片段）→ 问题 → 建议改成什么（给出英文改法）。

这篇论文事先定了下面这些硬要求，请逐条核查是否做到：

**A. 句子**
- 正文句长中位数目标 12-14 词；95% 的句子 ≤ 20 词；**超过 30 词的句子一句都不许有**。
- 一句只说一件事。不要用分号把两个独立句硬连起来。
- 不要长前置状语开头，先给主语。
- 一句最多一个 which/that 从句，不要从句套从句。
- 不要名词化动词（写 "the projection projects the command"，不写 "the performance of the projection of the command"）。
- **不许出现破折号**（em dash / en dash 当标点用）。`--` 只准用在数字区间。
- 不要 Furthermore / Moreover / It is worth noting that 这类注水连接词。

**B. 术语（锁死，全文不得出现变体）**
vessel（不用 ship/boat/craft）· own vessel（不用 ego vessel/ownship/own ship）·
target vessel（不用 obstacle vessel/other vessel）· give-way vessel · stand-on vessel ·
encounter situation（不用 encounter type/scenario）· head-on / crossing / overtaking ·
safety shield（不用 safety filter / safety layer / guard）· projection（不用 mapping/clipping）·
safe control set（不用 safe action set/admissible set）· action space · control command（不用 control input）·
actuator limits · quadratic program · fallback（不用 backup/contingency）· emergency situation ·
reinforcement learning · policy（指策略时不用 agent）· checkpoint · configuration（不用 arm/variant）·
seed · arrival rate · violation / violations per episode · episode · validation set / test set。
另：COLREGs 首次给全称，之后一律 COLREGs（不写 COLREG / COLREGS / ColRegs）。
**本文自己的方法一律称 Ours**，不要在某些地方写成 this paper / the proposed method / the full method。

**C. 语气：谦虚，不自夸**
不许出现 significantly outperforms / far superior / dramatically improves / excellent /
outstanding / state-of-the-art（自称）/ clearly demonstrates / We solve the problem of…。
让数字说话，形容词一个不要。"the first" 必须带 hedge（To the best of the authors' knowledge）。

**D. 用词圈定**
面向的是交通领域读者，不是机器学习专业读者。不要出现这一圈以外的黑话
（例如 infimum、zonotope、certified、epistemic 之类）。发现一处给一个替代说法。

**E. 其它体例**
- 数字四位及以上加千位逗号；数字与单位之间加空格，百分号不加空格。
- 拼写用美式（behavior / modeling / analyze），全文一致。
- 摘要 ≤ 300 词，且**零第一人称**（不出现 we / our）。
- 冠词、单复数、时态（方法用一般现在时、实验过程可用过去时）是否统一。

请按 A-E 分组输出问题清单，每组末尾给出该组的问题总数。
最后单独列一张表：**超过 30 词的句子**（全部列出，给出词数与拆句建议）。
```

## 【第 4 份】定位与学术英语风格核查

```
你是一位 TRB 年会的资深审稿人，现在为一篇投稿做**定位与写作风格**核查。

前提：
- 论文的方法论已冻结，不要提出任何修改算法、增加实验、调整模型的建议。
- 用中文回答，引用原句时保留英文原文。输出问题清单，不要写评语和鼓励。
- 每条必须写清：位置（节号 + 原句片段）→ 问题 → 建议改成什么。

**背景**：本文有一篇密切相关的对标工作（Krasowski and Althoff 2024，离散动作 + 动作屏蔽）。
该工作的作者**很可能就是本文的审稿人**。因此本文的写作方针是：
不贬低对方、不花篇幅讲对方算法的毛病、差别一律写成**取舍**而不是**缺陷**，
同时**必须保留一切确有借用的出处归属**（删掉出处比挂靠更严重）。

请检查：

1. **本文是否站在"我们提出了一套避碰算法"的位置上写**，而不是站在
   "我们在某某工作的基础上改了改"的位置上。请找出所有让论文显得像是附属工作的句子，
   例如 following X / as in X / consistent with X / we extend X / built upon X 这类挂靠句式。
   注意：术语与公式记号沿用领域惯例**不算**挂靠。

2. **是否有花篇幅讲对方毛病的地方**。把差别写成"缺陷"的句子找出来，给出改成"取舍"的写法。
   例如把 "Discretization loses continuous control and locks the precision to the grid"
   改成 "Discretization fixes the control resolution at the grid spacing"。

3. **对标工作的引用是否只出现在相关工作与实验两节**。出现在引言、方法、致谢里的，
   请逐处判断是否确有借用：确有的保留但改成事实性归属，没有的删掉。

4. **是否有抽象空泛的表述**。找出那些说了等于没说的句子，例如
   「本方法具有良好的性能」「该设计是有效的」「充分考虑了各种因素」这一类。
   在英文里表现为没有具体对象、没有数字、没有作用域的形容词句。

5. **是否有口水话 / 非学术表达**。找出口语化、含糊、带感情色彩的措辞，
   以及"讲道理式"的行文（例如反问句、"显然"、"众所周知"、第二人称）。

6. **贡献陈述是否站得住**。请逐条看引言末尾的贡献列表，判断每一条是否
   ① 具体到能被检验 ② 在正文里有对应的一节 ③ 措辞没有超出证据。

7. **标题、摘要五个小标题、各节标题**是否准确反映内容，有没有比正文更大的口气。

最后给出：定位是否清晰（是/否 + 理由三句话）+ 最该先改的五处。
```
