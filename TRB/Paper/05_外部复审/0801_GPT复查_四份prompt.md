# 给 GPT 的四份复查 prompt（2026-08-01 · v2）

## 怎么用

1. **每一份单开一个新会话。** 四份合并成一次问，它每项只会说两句就过去了。
2. 每个会话里，**先贴下面的〈开场白〉，再贴那一份的〈任务〉**，然后上传论文。
3. 拿回来的清单**先给我**，我这边核对完再改。

| 发哪一份 | 上传什么 |
|---|---|
| 第 1 份（文献） | `801-paper-英文版.tex` + `_refs.tex`（文献表原文，比 PDF 好核） |
| 第 2 / 3 / 4 份 | `801-paper-英文版_预览.pdf` |

## 〈开场白〉—— 四份共用，每次都先贴这一段

```
在开始之前，先把你这次的角色和边界定清楚。请严格遵守，不要越界。

【你是谁】
你是一位外部审查员。你这一轮**只负责找问题、列清单**。

【你不做什么 —— 这几条是硬边界】
1. **不要评论方法论。** 这篇论文的算法、模型、实验设计、数据采集全部已经冻结，
   改不动了。任何形如"建议换个算法""建议补一组实验""建议加一个模块""这个基线选得不好"
   的意见，对我们都是零价值，请一个字都不要写。
2. **不要重写论文。** 不要整段改写、不要给我一份"润色后的全文"、不要输出修改稿。
   你给出的是**问题清单**，改是我们自己改。
3. **不要给鼓励、评语、总体印象、打分之外的客套话。** 不写"这篇论文整体质量很高"这类。
4. **不要臆断。** 你无法确认的，标注「存疑，需人工核实」，不要为了凑数硬判，
   也不要因为"看起来像真的"就判为通过。

【你要交付什么】
一份编号的问题清单。每一条必须包含这三样，缺一不可：
  · **位置**：节号 + 原句片段（英文原文照抄，别改写）
  · **问题**：具体是什么毛病，一句话说清
  · **改法**：建议改成什么（涉及英文的，直接给出英文改法）
另外每条标一个严重度：`必改` / `建议改` / `可选`。

【语言与格式】
用中文写你的分析和建议，但**引用论文原句时保留英文原文**。
最后给一张汇总表：各严重度各多少条。

【背景，供你判断时参考，不需要你复述】
这是一篇投给 TRB（美国交通研究委员会）年会的论文，投稿要求是：
20 页硬上限、单栏、Times New Roman 10 pt、每页行号从 1 重排、
结构化摘要 300 词以内（五个固定小标题）、作者-年份制引用、不允许附录。
论文主题是无人水面船舶按《国际海上避碰规则》(COLREGs) 避碰，
方法是把规则的让路方向写成动作平面上的一个半平面约束，
再用二次规划把强化学习策略的连续控制指令投影到安全集合上。

明白了就回复"明白"，然后等我发具体任务和论文。
```

## 【第 1 份】文献与学术道德核查

```
任务：对这篇论文做**引用与学术道德核查**。只查引用，不查别的。

逐条检查参考文献表里的每一条，以及正文里每一处引用，回答下面六个问题：

1. **是否存在不存在的文献。** 逐条核对作者、年份、标题、期刊或会议名、卷期页码是否自洽。
   典型的伪造特征：作者与该领域不符、刊名与主题不搭、卷期与年份对不上、
   会议论文却给了期刊卷号、DOI 或 arXiv 编号格式异常。
   请把每一条判为「可确认存在 / 信息自洽但需人工核实 / 高度可疑」三档之一，
   并给出你判断的依据。

2. **是否存在张冠李戴。** 正文某处说「X 提出了 A」，而 A 实际上不是 X 的贡献；
   或把综述当成原始工作引；或把后续工作的结论算到先驱工作头上。
   请逐处核对「这句话主张的内容」与「被引文献实际做的事」是否匹配。

3. **是否存在引用支撑不了结论的情况。** 即文献是真的、作者也对，
   但它并不能支撑正文那句话。特别注意带数字、带阈值、带"首次/唯一"的句子。

4. **是否存在该引而未引。** 正文里出现了明显来自他人的参数、阈值、判据、数据集、
   评价口径或公式形式，却没有给出处。**这一条比多引严重得多，请重点找。**

5. **自引与致谢是否得当。** 论文致谢里感谢了公开场景库与规则形式化的提供方，
   请判断这个致谢与正文里对该工作的引用是否一致、有没有过度或不足。

6. **引用格式是否统一。** 本文用作者-年份制（Chicago author-date），
   正文写 (Author, Year)，文献表按第一作者姓氏字母序、悬挂缩进、不编号。
   请找出格式不一致的条目。

最后给一张总表：文献总数 / 判为「高度可疑」几条 / 判为「需人工核实」几条 /
张冠李戴几处 / 该引未引几处。
```

## 【第 2 份】叙事与逻辑核查

```
任务：对这篇论文做**叙事完整性与逻辑严密性**核查。不涉及方法论优劣，只看论证本身是否自洽。

本文自己声明的叙事主线是这一条，请以它为基准：
「让路条款有方向性 → 合规无法用有没有撞上来验证 → 既有两条路各放弃一项属性 →
本文的洞见：让路条款在控制量平面上恰好是一个半平面 → 于是"枚举并屏蔽"可换成"向凸集投影" →
半平面 ∩ 动作箱 ∩ 单步无碰 = 凸集 → 二维二次规划投影 → 盾在训练回路之内 →
分级说明证了什么、没证什么 → 单变量递进序列把每个机制单独读出来 → 如实报代价。」

请检查：

1. **每一节、每一段是否都落在这条线上。** 找出偏离主线、整段删掉也不损伤论证的部分。

2. **摘要与引言里许下的每一个承诺，正文是否都兑现了。**
   请逐条列出摘要里的主张，标注它在正文哪一节被兑现；没兑现的单独列出。

3. **数字是否全篇一致。** 同一个量在摘要、正文、表、图注里出现多次时是否完全一致。
   请把所有出现两次以上的数字列成对照表，标出不一致的。

4. **每一张图、每一张表是否都有配套的分析文字**，且图上画的与正文说的是同一件事、
   同一个数据口径。反过来，正文里描述的现象是否都能在图上看到。
   **特别注意：本文的图有的取自训练过程、有的取自测试集，两者口径不同**，
   请检查图注与正文有没有把它们混为一谈。

5. **因果链条是否有跳步。** 找出「A 所以 B」但中间缺一环的地方。

6. **结论是否超出证据。** 本文明确声明只能严格证明三件事：
   远场单步无碰、每一个投影可行的让路步方向合规、迫近不可避的单向充分条件；
   其余都是经验结果。请找出任何在措辞上超出这个范围的句子。

7. **局限是否写全。** 找出从正文数据里能看出、但局限段没提的问题。

最后给出：叙事完整度 1-10 分（一句话说明扣分在哪）+ 最该先改的三处。
```

## 【第 3 份】语言表达核查 🔴 **这一份的边界最窄，请特别注意**

```
任务：对这篇论文做**纯语言层面**的核查。

【再强调一次你这一份的边界】
你这一份**只负责语言表达**：措辞、句法、术语一致性、体例、以及**去除任何 AI 生成的味道**。
- 内容对不对、方法好不好、实验够不够 —— **一个字都不要提**，那不是你这一份的事。
- 不要重写段落，不要给我润色后的全文。**只给问题清单。**
- 修改由我们自己完成，你只需要把潜在问题指出来。

请按下面五组逐项核查。

──────────────────────────────────
【A 组】🔴 AI 味 —— 这一组是本次的重点
请以"一位资深期刊编辑一眼能不能看出这是机器写的"为标准，找出所有可疑之处：

A1. **套话词与万能词**。例如 delve / leverage / underscore / pivotal / seamless /
    nuanced / landscape / realm / crucial / vital / showcase / testament /
    paves the way / cutting-edge / harness / myriad / plethora / meticulous /
    intricate / holistic / synergy / comprehensive / robust（当形容词滥用时）。
A2. **注水连接词**。Furthermore / Moreover / Additionally / It is worth noting that /
    It should be noted that / In conclusion / Overall / In summary。
A3. **三段式排比与"总-分-总"的机械结构**。典型症状：每段都是
    "主张句 + 三个并列理由 + 收束句"，读起来像模板。
A4. **过度对仗的句式**，例如 "Not only… but also…"、"On the one hand… on the other hand…"
    连续出现。
A5. **空洞的评价性句子**。没有具体对象、没有数字、没有作用域的形容词句，
    例如 "the method is effective"、"the results are promising"。
A6. **破折号（em dash / en dash）当标点用**。本文规定只准把 `–` 用在数字区间（页码、范围）。
A7. **过度对称的列表**，每一项长度、句式都一模一样，像生成的。
A8. **其它你认为"读起来不像人写的"的地方** —— 这一条请大胆列，宁多勿少，
    每条说明你觉得可疑的具体理由。

──────────────────────────────────
【B 组】句子
- 正文句长中位数目标 12-14 词；95% 的句子不超过 20 词；**超过 30 词的一句都不许有**。
- 一句只说一件事，不要用分号把两个独立句硬连起来。
- 不要长前置状语开头，先给主语。
- 一句最多一个 which/that 从句，不要从句套从句。
- 不要名词化动词：写 "the projection projects the command"，
  不写 "the performance of the projection of the command"。

**请单独列一张表：全文所有超过 30 词的句子**，给出词数与拆句建议。

──────────────────────────────────
【C 组】术语（锁死，全文不得出现变体）
vessel（不用 ship / boat / craft）· own vessel（不用 ego vessel / ownship / own ship）·
target vessel（不用 obstacle vessel / other vessel）· give-way vessel · stand-on vessel ·
encounter situation（不用 encounter type / encounter scenario）·
head-on / crossing / overtaking · safety shield（不用 safety filter / safety layer / guard）·
projection（不用 mapping / clipping）· safe control set（不用 safe action set / admissible set）·
action space · control command（不用 control input）· actuator limits · quadratic program ·
fallback（不用 backup / contingency）· emergency situation · reinforcement learning ·
policy（指策略时不用 agent）· checkpoint · configuration（不用 arm / variant）· seed ·
arrival rate · violation / violations per episode · episode · validation set / test set。

另外两条：
- COLREGs 首次出现给全称，之后一律 COLREGs（不写 COLREG / COLREGS / ColRegs）。
- **本文自己的方法一律称 Ours**，不许在别处写成 this paper / the proposed method /
  the full method / our approach。

──────────────────────────────────
【D 组】语气：谦虚，不自夸
不许出现：significantly outperforms / far superior / dramatically improves /
excellent / outstanding / state-of-the-art（自称）/ clearly demonstrates /
We solve the problem of…。
让数字说话，形容词一个不要。"the first" 必须带 hedge（To the best of the authors' knowledge）。

──────────────────────────────────
【E 组】体例
- 面向交通领域读者，不是机器学习专业读者。不要出现这一圈以外的黑话
  （例如 infimum、zonotope、certified、epistemic）。发现一处给一个替代说法。
- 数字四位及以上加千位逗号；数字与单位之间加空格，百分号不加空格。
- 拼写用美式（behavior / modeling / analyze），全文一致。
- 摘要 300 词以内，且**零第一人称**（不出现 we / our）。
- 冠词、单复数、时态是否统一（方法用一般现在时，实验过程可用过去时）。

──────────────────────────────────
输出：按 A-E 分组，每组末尾给出该组问题总数。
A 组请排在最前面，并且不要因为"整体读起来还行"就少列。
```

## 【第 4 份】定位与学术英语风格核查

```
任务：对这篇论文做**定位与写作风格**核查。

【背景 —— 这一条决定你怎么判】
本文有一篇密切相关的对标工作（Krasowski and Althoff 2024，离散动作 + 动作屏蔽）。
**该工作的作者很可能就是本文的审稿人。** 因此本文的写作方针是：
不贬低对方、不花篇幅讲对方算法的毛病、差别一律写成**取舍**而不是**缺陷**；
同时**必须保留一切确有借用的出处归属** —— 删掉出处比挂靠更严重。

请检查：

1. **本文是否站在"我们提出了一套避碰算法"的位置上写**，
   而不是站在"我们在某某工作的基础上改了改"的位置上。
   请找出所有让论文显得像附属工作的句子，例如 following X / as in X /
   consistent with X / we extend X / built upon X 这类挂靠句式。
   注意：术语与公式记号沿用领域惯例**不算**挂靠，不必回避。

2. **是否有花篇幅讲对方毛病的地方。** 把差别写成"缺陷"的句子找出来，给出改成"取舍"的写法。
   例：把 "Discretization loses continuous control and locks the precision to the grid"
   改成 "Discretization fixes the control resolution at the grid spacing"。

3. **对标工作的引用是否只出现在相关工作与实验两节。**
   出现在引言、方法、致谢里的，请逐处判断是否确有借用：
   确有的保留但改成事实性归属，没有的删掉。

4. **是否有抽象空泛的表述。** 找出说了等于没说的句子，
   在英文里表现为没有具体对象、没有数字、没有作用域的形容词句。

5. **是否有口水话或非学术表达。** 找出口语化、含糊、带感情色彩的措辞，
   以及"讲道理式"的行文（反问句、"显然"、"众所周知"、第二人称）。

6. **贡献陈述是否站得住。** 逐条看引言末尾的贡献列表，判断每一条是否
   ① 具体到能被检验 ② 在正文里有对应的一节 ③ 措辞没有超出证据。

7. **标题、摘要的五个小标题、各节标题**是否准确反映内容，有没有比正文更大的口气。

最后给出：定位是否清晰（是 / 否 + 三句话理由）+ 最该先改的五处。
```
